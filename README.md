# PROYECTO-SIST-DIST
Proyecto para la UEES. Objetivo, explicarlo oralmente el proximo miercoles. Entregar el 15 de Junio( MARTES A LAS 23:59)

## Estudiante 1
Aplicación de Inventario (Cualquier lenguaje)

Desarrollará una aplicación, ejecutada dentro de un contenedor Docker, que permita gestionar el inventario de productos. Esta aplicación deberá conectarse a la base de datos que corre en la máquina del Estudiante 2 usando la dirección IP que Tailscale (maquinas diferentes) asigna a esa máquina.

## Estudiante 2
Base de Datos y Sistema de Reportes

Administrará dos contenedores en su máquina, ambos conectados a través de una red Docker interna personalizada.
